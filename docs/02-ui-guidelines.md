# 02. UI 구현 지침

## 참고 이미지 해석
첨부 이미지는 정면 영화관을 보여준다. 주요 시각 요소는 **짙은 붉은 벨벳 커튼, 중앙의 밝은 와이드 스크린, 화면 아래쪽의 붉은 극장 좌석**이다. 이 이미지를 서비스의 시각적 방향으로 삼되, 실제 UI는 텍스트 입력과 영화 정보가 가장 잘 읽히도록 구성한다.

## 디자인 방향
- 분위기: 클래식 영화관, 따뜻하고 몰입감 있는 시네마 무드.
- 기본 배경: 거의 검정에 가까운 차콜/버건디.
- 강조색: 커튼을 연상시키는 딥 레드와 포인트 레드.
- 콘텐츠 카드: 어두운 버건디 또는 차콜 패널, 충분한 여백과 명확한 경계.
- 본문 텍스트: 밝은 아이보리, 보조 텍스트는 대비가 충분한 회색.
- 스크린 영역은 밝은 아이보리 패널로 표현할 수 있으나 실제 추천 결과 텍스트는 눈부시지 않게 어두운 글자를 사용한다.

## 레이아웃
1. **헤더**: 작은 필름/상영관 분위기의 워드마크와 서비스명. 불필요한 메뉴는 넣지 않는다.
2. **히어로**: 커튼이 열린 극장 스크린을 연상시키는 넓은 영역. 중앙에 “오늘 어떤 영화를 보고 싶나요?”와 입력 폼을 둔다.
3. **추천 결과**: 대표 추천을 가장 먼저 보여주는 큰 카드. 제목, 개봉일, 러닝타임, 짧은 소개를 명확히 구분한다.
4. **비슷한 영화**: 대표 추천 아래에 최대 3개의 간결한 카드/행으로 표시한다.
5. **피드백**: 페이지 하단. 입력 폼 다음에 최신순 피드백 목록을 둔다.

## 참고 이미지 적용 방법
- 원본 이미지를 배경으로 무조건 늘려 쓰지 않는다. 화면 비율이 달라지면 커튼·스크린이 잘릴 수 있다.
- 가능하면 CSS로 커튼/스크린/좌석을 단순화해 재현하거나, 원본 이미지를 히어로의 제한된 장식 요소로 사용한다.
- 원본 이미지를 사용할 경우 `object-fit: cover`와 적절한 `object-position`을 적용하고, 입력 폼 뒤에 충분한 반투명 오버레이를 둔다.
- 이미지가 로드되지 않아도 입력 폼과 콘텐츠가 정상적으로 보이도록 배경색을 지정한다.
- 이미지 파일을 프로젝트에 포함해야 한다면 `public/assets/`로 복사하고 파일명을 `cinema-reference.png`로 정리한다. 원본 파일의 존재를 가정하지 말고 에이전트가 실제 파일을 확인한다.

## 반응형 기준
- 1200px 이상: 콘텐츠 최대 폭 약 1080px, 추천 카드와 유사 영화 영역을 넉넉하게 배치.
- 768~1199px: 좌우 여백 축소, 카드 간격 조정.
- 767px 이하: 단일 열, 버튼은 누르기 쉬운 높이, 긴 제목은 줄바꿈.
- 고정 폭·고정 높이로 본문이 잘리는 레이아웃을 만들지 않는다.

## 접근성 및 상호작용
- 모든 입력에는 보이는 레이블 또는 접근 가능한 이름을 제공한다.
- 버튼·입력의 키보드 포커스 표시를 제거하지 않는다.
- 텍스트 대비를 충분히 확보한다.
- 로딩, 성공, 오류는 문구와 아이콘/형태를 함께 사용한다.
- 애니메이션은 짧고 절제하며 `prefers-reduced-motion`을 존중한다.

## 완료 기준
- [ ] 첨부 이미지의 붉은 커튼·밝은 스크린·붉은 좌석 분위기가 디자인에 반영된다.
- [ ] 입력 폼이 첫 화면에서 쉽게 발견된다.
- [ ] 영화 정보의 제목·날짜·시간·설명이 한눈에 구분된다.
- [ ] 피드백 섹션이 페이지 하단에 있고 최신순 목록이 폼 아래에 위치한다.
- [ ] 모바일 폭에서 가로 스크롤이 발생하지 않는다.
- [ ] 텍스트 대비와 키보드 포커스가 확인된다.
